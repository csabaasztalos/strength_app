# DogPack - strength app
Egy Laravel és SQLite alapú coaching webalkalmazás.

## Funkciók
- Felhasználói regisztráció, e-mailes megerősítés és újramegerősítés
- Elfelejtett jelszó kezelése
- Bejelentkezés és kijelentkezés
- Főoldal megtekintése

### Athlete felhasználók
- Összes aktív  edzés program megtekintése
- Aktív programok indítása és megállítása
- Legfeljebb 2 program egyidejű futtatása
- Programhoz tartozó, opcionális gyakorlat-maximumok megadása és egyéni súlyszámítás
- Program napok teljesítése, átugrása
- Jegyzetek hozzáadása az edzésnapokhoz
- Profiladatok szerkesztése
  
### Coach felhasználók
- Gyakorlatok teljes CRUD kezelése
- Programok teljes CRUD kezelése
- Programgyakorlatok teljes CRUD kezelése
  
## Technológiák
- Laravel 13
- PHP - 8.4
- SQLite
- Blade
- HTML, Tailwind és CSS
- JavaScript
