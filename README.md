# DogPack - strength app
Egy Laravel és SQLite alapú coaching webalkalmazás.

## Funkciók
- Felhasználói regisztráció, e-mailes megerősítés, újramegerősítés, elfelejtett jelszó és bejelentkezés
- Főoldal megtekintése

- Bejelentkezett "athlete" felhasználók
  - Összes Active edzés program megtekintése
  - Programok indtítása és megállítása
  - Maximum 2 program egyidejű futtatása
  - Programnak megfelelő opcionális gyakorlat maximumok megadása -> egyéni súly számítás
  - Program napok teljesítése, átugrása, és jegyzet hozzáadás
  - Profil adatok szerkesztése
  
- Bejelentkezett "coach" felhasználók
  - Gyakorlatok, Programok, Program gyakorlatok tejles CRUD

## Technológiák
- Laravel 13
- PHP - 8.4
- SQLite
- Blade
- HTML, Tailwind és CSS
- JavaScript
